# Disaster Recovery — lottery-swara

## Where data lives
- **Code:** this GitHub repo (idletoaster/lottery-swara)
- **Cached scrape data:** `jackpot_data.json` on disk (NOT in git)
- **Ephemeris binaries:** `ephe/` on disk (NOT in git, ~763MB)
- **Restic backup:** google-drive:backup/lottery-swara  (5-day retention)
- **Backup cron:** 30 3 * * *   /home/pawan/bin/backup-45.19.sh

## What is captured by restic
The whole `~/lottery-swara` tree, **except**:
- `node_modules/` and `api/node_modules/`  (regenerated by `npm install`)
- `.git/`                                  (this is on GitHub, no need to back up)

So the captured non-regenerable assets are:
- `jackpot_data.json`        — Python scrape cache
- `ephe/`                    — Swiss Ephemeris binaries
- `deploy.sh`, `scraper.py`, `api/server.js`, `index.html`, PWA assets

## On a fresh Ubuntu host
1. `apt install -y restic build-essential python3 && (curl -fsSL https://rclone.org/install.sh | sudo bash)`
2. Clone the code:
       gh repo clone idletoaster/lottery-swara
3. Drop the rclone config and the restic passphrase file:
       ~/.config/rclone/rclone.conf     (mode 600)
       ~/.secrets/restic_passphrase_lottery-swara   (mode 600)
4. Restore the live data on top of the clone (this brings `ephe/` and `jackpot_data.json` back):
       restic -r "rclone:google-drive:backup/lottery-swara" \
              --password-file ~/.secrets/restic_passphrase_lottery-swara \
              restore latest --target /
5. Reinstall Node deps with the Swiss Ephemeris native binding:
       cd ~/lottery-swara/api && npm install
6. Start PM2 processes:
       pm2 serve ~/lottery-swara 8000 --name swara-web --spa
       pm2 start ~/lottery-swara/api/server.js --name swara-api

There's also a wrapper script on the source server at
`/home/pawan/restore-45.19.sh` that does steps 3–4 for both repos.

## Daily scraper
`/usr/bin/python3 /home/pawan/lottery-swara/scraper.py` runs at 21:00
via cron (re-populates `jackpot_data.json`). Re-add that cron line if
restoring from scratch.
